# Git Automation Dashboard 0.27.1 Release Notes

## Summary
Git Automation Dashboard 0.27.1 resolves an issue where older draft releases returned by GitHub's API could obscure newer published releases on repository cards. All release listings are now sorted chronologically by publication/creation date, ensuring accurate latest-release detection and consistent release management order. In addition, the project test script has been updated to run cleanly across platforms.

## What's Changed

### GitHub Latest Release Resolution
- Added release helper utilities (`sortGitHubReleases`, `findLatestRelease`, `mapGitHubReleaseToReleaseInfo`) that sort releases chronologically by publication/creation date.
- Corrected `get-latest-release` to evaluate sorted releases rather than relying on GitHub's default draft-first ordering, ensuring repositories with older drafts display the true latest published release.
- Updated `get-all-releases` to also sort releases chronologically so repository modal release histories reflect the actual release timeline.
- Added comprehensive unit tests covering draft handling, semantic version tie-breaking, and pre-release filtering settings.

### Cross-Platform Test Execution
- Replaced the platform-dependent `rm -rf` command in the `test` npm script with Node's native `fs.rmSync` and aligned test file globbing for cross-platform execution.

## Breaking Changes
- None. This release is backwards compatible.

## Upgrade Notes
- No special upgrade steps required.
