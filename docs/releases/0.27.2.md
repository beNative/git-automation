# Git Automation Dashboard 0.27.2 Release Notes

## Summary
Git Automation Dashboard 0.27.2 fixes an issue where selecting an executable for a Launch Configuration did not provide any controls to choose or specify the executable file. Users can now select from auto-detected repository executables, browse their local filesystem with native file filtering via a "Browse..." button, or manually specify an executable path. In addition, executable launch resolution now seamlessly supports both relative and absolute paths, and the dynamic executable selection modal includes an on-demand browse fallback.

## What's Changed

### Launch Configuration Executable Selection
- Fixed the Launch Configuration editor in `RepoFormModal` to render an executable selector when the "Select Executable" type is chosen.
- Added a path input with autocomplete suggestions, a quick-select dropdown for auto-detected executables, and a native "Browse..." button connected to the OS file picker.
- Added `executablePath?: string` to the `LaunchConfig` type definition and ensured dashboard cards and menus launch configured executables directly.

### Cross-Platform Path Resolution & Launching
- Created `electron/launchHelpers.ts` with `normalizeExecutablePath` (for making repository-local paths relative) and `resolveExecutablePath` (for resolving relative or absolute target executables and working directories).
- Updated the `launch-executable` IPC handler to use robust path resolution, avoiding malformed path concatenation across drives on Windows.
- Added native file picker filters (`.exe`, `.bat`, `.cmd`, `.sh`, etc.) for easier executable discovery.

### Executable Selection Modal Polish
- Updated `ExecutableSelectionModal` to include an on-demand "Browse for executable..." button and clear empty-state messaging when no executables are found in standard build directories (`dist`, `release`, `build`, `out`, `bin`).
- Updated `LaunchSelectionModal` to display the executable path and appropriate icon for manual executable launch configs.

### Automated Tests
- Added unit tests in `tests/launchHelpers.test.ts` covering path normalization, relative resolution, absolute path preservation, and empty repo path fallbacks.

## Breaking Changes
- None. This release is backwards compatible.

## Upgrade Notes
- No special upgrade steps required.
